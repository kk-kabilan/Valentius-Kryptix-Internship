# Task 1 – Linear Regression from Scratch

**Internship:** Valentius Kryptix

## Objective
Implement a Linear Regression model from scratch using NumPy without using Scikit-learn or Statsmodels for model training.

## Implementation
- Hypothesis function
- Mean Squared Error cost function
- Gradient calculation
- Gradient Descent optimization
- Feature scaling
- Learning rate comparison
- Test-set evaluation
- Comparison with Scikit-learn LinearRegression

## Dataset
California Housing Dataset

- Samples: 20,640
- Input features: 8
- Target: Median House Value

## Results

| Metric | NumPy | Scikit-learn |
|---|---:|---:|
| Test R² | 0.593660 | 0.593596 |
| Intercept | 2.063477 | 2.063477 |
